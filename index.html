How to use Safety Tracker for your role.

Admin

Bulk import, system controls and backup.

Bulk Import

Upload complete section PDFs. Safety Tracker analyses them locally, splits clearly referenced documents, compares each existing record with the current tracker copy, organises them into the correct section, and shows a preview before anything is saved.

Built-in rules: RA and COSHH → Documents / self-training; SSW → Documents / instructor-led; SDS/MSDS → reference-only with no assignment or signature; Toolbox Talks → Training / instructor-led. Directory/index files are stored as control records.

Automatic change detection: filenames are ignored. The actual PDF text is fingerprinted and compared with the current tracker copy. Unchanged records are skipped automatically; changed records are selected as a new version.

You can select several packs at once. Maximum 45 MB per PDF.

Backup

Create a database-only JSON backup or a full ZIP containing the database export plus all uploaded safety/training files.
